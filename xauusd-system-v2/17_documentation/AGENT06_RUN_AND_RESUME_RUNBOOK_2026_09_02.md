# Agent-06 local run and resume runbook

Date: 2026-09-02

This runbook covers the private local Anthropic Agent-06 validation workflow for the frozen 173-case XAUUSD V2 blind corpus.

## Safety invariants

- The private evidence ZIP stays outside the public repository.
- The Anthropic API key is supplied only through the hidden local prompt/environment and is never written to disk by the pipeline.
- The blind provider process does not load ground truth and does not perform comparison.
- Comparison happens only after blind outputs are frozen and hashed.
- Every persisted artifact keeps `promotion_allowed=false`.
- A completed blind run, comparison, or audit never auto-promotes strategy knowledge or rules to VERIFIED.
- Live execution remains disabled.

## Fresh run

From the repository checkout with the editable environment active:

```bash
xauusd-v2-agent06-local \
  --bundle "$HOME/Downloads/xauusd_agent06_primary_bundle_2026_09_02.zip" \
  --model claude-sonnet-5
```

The command builds a new run ID such as:

```text
agent06-anthropic-20260902T203500Z
```

The provider stage now prints per-case progress:

```text
[case 1/173] GT-... COMPLETE
[case 2/173] GT-... ABSTAIN
...
```

After every successfully completed case, the blind process atomically updates a private checkpoint:

```text
~/.xauusd-agent06/runs/<run-id>/agent06_blind_checkpoint.json
```

The checkpoint contains decisions and evidence fingerprints only. It contains no ground truth, no comparison result and no promotion authority.

## Taxonomy transport

The Anthropic wire contract uses explicit transport codes `L001` through `L173` rather than asking the provider to count a zero-based index or emit arbitrary taxonomy text.

The local runner deterministically maps the selected code back to the frozen taxonomy label.

If Anthropic returns a malformed or out-of-range taxonomy code, that individual case becomes a fail-closed abstention with confidence `0.0`; it does not crash the full 173-case batch.

## Interrupted run

If a run started on the checkpoint-enabled code and later fails because of a provider/network/rate-limit condition, do not delete its private run directory and do not start another fresh run immediately.

Record the run ID shown by the failed run. Resume with:

```bash
xauusd-v2-agent06-local \
  --bundle "$HOME/Downloads/xauusd_agent06_primary_bundle_2026_09_02.zip" \
  --model claude-sonnet-5 \
  --resume-run-id <run-id>
```

The resume path rebuilds private staging from the pinned source ZIP and then verifies before reusing a single case:

- same run ID;
- same model provider;
- same exact model;
- same Git commit;
- same blind packet SHA-256;
- same taxonomy SHA-256;
- same source locator;
- same primary text SHA-256;
- same image MIME/SHA-256/byte-size fingerprints;
- no ground-truth-loaded flag;
- no comparison-performed flag;
- `promotion_allowed=false`.

Only checkpointed cases that pass all these checks are skipped. Remaining cases call the provider normally.

## Important Git rule for resume

Do not `git pull`, change branch, amend code, or otherwise change the repository commit between an interrupted run and its resume.

Resume is intentionally bound to the exact original Git commit. Mixing predictions generated by different code revisions into one blind run is rejected.

If a code change is genuinely required to fix the failure, the old partial run remains an incomplete historical attempt and a new fresh run must be started from the new tested commit.

## Older failed runs

Runs created before checkpoint/resume support cannot be resumed. They did not persist a safe per-case checkpoint contract. They remain incomplete attempts only.

## Successful completion

A successful local pipeline proceeds through:

1. build frozen answer-free packet;
2. execute 173-case isolated blind provider run;
3. freeze and hash blind outputs;
4. deterministic post-run ground-truth comparison.

Final success marker:

```text
LOCAL_AGENT06_PIPELINE_COMPLETE
```

Expected final persisted artifacts include:

- `agent06_blind_checkpoint.json`;
- `agent06_blind_predictions.json`;
- `agent06_runtime_manifest.json`;
- `agent06_readiness.json`;
- `agent06_frozen_output_hashes.json`;
- `agent06_comparison.json`;
- `agent06_local_pipeline_summary.json`.

After completion, run the separate strict post-run auditor before making any independent-validation claim.
