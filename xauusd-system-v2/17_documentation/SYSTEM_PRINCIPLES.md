# XAUUSD V2 — SYSTEM PRINCIPLES

1. **Μηδενική κληρονομιά:** κανένα legacy αρχείο, rulebook, trade, glossary ή συμπέρασμα δεν είναι πηγή του V2 χωρίς ρητή έγκριση χρήστη.
2. **Καμία εφεύρεση:** αν η πηγή δεν ορίζει κάτι, το σύστημα το σημειώνει ως ασαφές/άγνωστο.
3. **Provenance παντού:** κάθε γνώση και κανόνας πρέπει να δείχνει ακριβή πηγή και locator (σελίδα, timestamp, εικόνα κ.λπ.).
4. **Draft by default:** output AI = υποψήφιο/draft, ποτέ αυτόματα verified.
5. **Human approval:** μόνο ρητή ανθρώπινη έγκριση ή προκαθορισμένη πιστοποιημένη διαδικασία μπορεί να προάγει γνώση/κανόνα.
6. **Versioning:** κάθε κανόνας και στρατηγική έκδοση είναι ιχνηλάσιμη.
7. **Ambiguity = NO TRADE:** η αβεβαιότητα δεν συμπληρώνεται με υπόθεση.
8. **Separation of duties:** κατανόηση, formalization, validation, risk και execution είναι χωριστά συστήματα.
9. **Risk veto:** ο deterministic risk engine έχει δικαίωμα απόλυτου veto.
10. **No LLM execution authority:** γλωσσικό μοντέλο δεν στέλνει live order.
11. **Reproducibility:** κάθε απόφαση/τεστ πρέπει να μπορεί να ανακατασκευαστεί από inputs, versions και logs.
12. **Promotion gates:** καμία αλλαγή δεν περνά production χωρίς προκαθορισμένα validation stages.
