# XAUUSD SYSTEM V2

Νέο, απομονωμένο σύστημα στρατηγικής για XAUUSD.

## Κανόνας μηδενικής κληρονομιάς
Κανένα παλιό rulebook, trade, glossary, dataset ή συμπέρασμα από το legacy MR Casino project δεν θεωρείται έγκυρη πηγή για το V2, εκτός αν εγκριθεί ρητά από τον χρήστη ως πηγή της νέας στρατηγικής.

## Δομή
- 01_sources: μόνο νέο εγκεκριμένο υλικό
- 02_raw_knowledge: ακατέργαστη εξαγωγή γνώσης
- 03_verified_knowledge: μόνο επαληθευμένη γνώση
- 04_glossary: ορολογία νέας στρατηγικής
- 05_rules: μηχανικοί κανόνες
- 06_examples: εγκεκριμένα σωστά/λάθος παραδείγματα
- 07_agents: πράκτορες AI και οδηγίες τους
- 08_market_data: δεδομένα XAUUSD
- 09_indicator: λογική indicator
- 10_backtesting: ιστορικές δοκιμές
- 11_validation: ανεξάρτητη επαλήθευση
- 12_risk: διαχείριση κινδύνου
- 13_execution: εκτέλεση συναλλαγών
- 14_dashboard: κεντρικός πίνακας ελέγχου
- 15_tests: αυτοματοποιημένοι έλεγχοι
- 16_logs: αρχεία καταγραφής
- 17_documentation: τεχνική τεκμηρίωση

## Αρχή λειτουργίας
Το AI δεν επιτρέπεται να εφευρίσκει κανόνες. Κάθε κανόνας πρέπει να έχει πηγή, έκδοση, κατάσταση επαλήθευσης και σαφή ιδιοκτησία αλλαγής.
