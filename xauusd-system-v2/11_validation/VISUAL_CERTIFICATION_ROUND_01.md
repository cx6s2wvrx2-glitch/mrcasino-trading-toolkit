These charts/annotations are primary evidence, but none is promoted merely because an annotation exists.

Before a rule becomes VERIFIED, the same concept still requires:
1. positive examples;
2. negative lookalikes;
3. edge cases;
4. exact mechanical conditions;
5. independent relabelling;
6. historical reproducibility using only information available at the timestamp.
